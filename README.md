# MNIST CNN Experiment

## 手書き数字画像を用いたCNNの学習と条件比較

MNIST（Modified National Institute of Standards and Technology database）の手書き数字画像を用いて、Convolutional Neural Network（畳み込みニューラルネットワーク；CNN）の学習と評価を行うJupyter Notebookです。

本教材は、CNNを実行して分類精度を求めるだけでなく、ネットワーク構造や学習条件を一つずつ変更し、条件を統制した比較実験を行うことを目的としています。

## 学習目標

このNotebookを通して、以下を学びます。

* 画像が画素値の二次元配列として表現されること
* CNNによる画像分類の基本的な流れ
* 学習データ、検証データ、テストデータの役割
* ネットワーク構造とハイパーパラメータの違い
* 一度に一条件だけを変更する比較実験の考え方
* 学習曲線、分類精度および誤分類画像の読み取り方
* 実験結果から言えることと、言えないことの区別

## 使用するデータ

Kerasから取得できるMNISTデータセットを使用します。

MNISTには、0から9までの手書き数字を表す28×28画素のグレースケール画像と、各画像の正解ラベルが含まれています。Notebookの実行時に自動的にダウンロードされるため、事前に画像ファイルを用意する必要はありません。

標準課題では、データを以下のように分けて使用します。

| 用途     |     画像数 | 役割                 |
| ------ | ------: | ------------------ |
| 学習データ  | 50,000枚 | モデルのパラメータを学習する     |
| 検証データ  | 10,000枚 | CNNの構造や学習条件を比較する   |
| テストデータ | 10,000枚 | 採用する条件を決めた後に最終評価する |

テストデータの結果を見ながら条件を変更すると、テストデータに適合した条件を選ぶことになります。そのため、条件の比較には検証データを使用し、テストデータは最終評価にのみ使用します。

## 標準課題：CNNの条件比較

最初に、Notebookで指定された基準CNNを学習・評価します。その後、以下から一つ以上の条件を選び、原則として一度に一条件だけを変更します。

* 畳み込み層の数
* フィルタ数
* Dropout率
* 学習回数
* バッチサイズ

標準課題では、学習・検証・テストデータの画像数を変更しません。

各実験について、次の情報を記録します。

* CNNの構造
* 学習条件
* 変更した条件と変更理由
* 検証データに対する分類精度
* 学習時間
* 学習曲線
* 誤分類された画像
* 結果から考えられること

## 発展課題1：学習データ数と分類性能

検証データとテストデータは変更せず、学習データ数だけを複数条件で減らします。

学習データを減らす際は、特定の数字だけが多くなったり少なくなったりしないように、0から9までの数字の枚数に注意してください。

学習データ数と以下の関係を比較します。

* 分類精度
* 学習時間
* 学習曲線
* 誤分類される数字や画像

データ数以外の影響が混ざらないように、CNNの構造や学習条件は同じにします。

## 発展課題2：画像の変形に対する頑健性

標準課題で学習したモデルを固定し、評価画像に以下のいずれか一つの変形を加えます。

* 平行移動
* 回転
* ノイズ付加

変形の強さを複数条件で変え、変形前後の分類精度と誤分類画像を比較します。

最初は一種類の変形だけを扱ってください。複数種類の変形を同時に加えると、どの変形が結果に影響したのかを判断しにくくなります。

## 比較実験における注意

* 比較したい条件以外は、できるだけ同じに保ってください。
* 変更した条件と固定した条件を記録してください。
* 乱数の影響により、同じ条件でも結果が完全には一致しない場合があります。
* 一回の実行結果だけで、一般的な結論を出さないようにしてください。
* 分類精度だけでなく、学習時間、学習曲線および誤分類例も確認してください。
* 最も高い精度を得ることだけを目的とせず、結果が変化した理由を考察してください。
